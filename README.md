# SafeAI-with-Copilot-Chat-Learning-Path
This repository contains sourcesto set up and implement a foundational learning path for end users. It gives you everything to set it up on your own and customize as needed - or the complete SCORM file to download and directly integrate in your LMS.

It's meant to educate the broad organization in basic workplace AI topics, foundational considerations as well as where to find and how to use Copilot Chat.
